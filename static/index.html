等待操作
身份（请求头 X-User-Id / X-Role）
1. 登记转运批次（观察须为 submitted）

2. 批次动作
离场测温 ℃

常用接口

GET  /health
GET  /api/<kind>                       # kind: observations / samples / clusters / transport_batches
POST /api/<kind>                       # 创建；转运批次重复箱号返回首次结果
GET  /api/entities/<id>
POST /api/entities/<id>/actions       # {"action":"动作名","data":{...},"expected_version":n}
GET  /api/audit?entity_id=<id>         # 交接与温度动作均有审计
